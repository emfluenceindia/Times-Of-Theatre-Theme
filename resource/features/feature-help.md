Important Website Features I Recommend

Beyond the flowchart, these features will make the website much more useful:

1. Separate “Courses” and “Workshops”

They serve different visitor intentions:

Courses: structured, longer-term learning programmes
Workshops: short-term, focused learning experiences
2. A Dedicated Mentor Database

A mentor profile should be reusable across:

Courses
Workshops
YouTube programmes
Archive projects
3. A Searchable Audio Archive

If preservation is a core mission, the archive should eventually support:

Search by title
Artist / narrator
Genre
Author
Year
Duration
Play / listen functionality
4. Individual Pages for Every Course and Workshop

Each page should include:

Overview
Learning outcomes
Mentor
Dates and duration
Fees
Eligibility
Registration / enquiry
Related photos or videos
5. Distinct Calls to Action

The website should guide visitors toward specific actions:

Learn → Listen → Watch → Attend → Enrol → Collaborate
